# Store listing — Markscope

## Name
Markscope — Markdown Reader for Developers

## Short description (≤ 132 chars)
Fast, secure Markdown viewer: GFM, Mermaid, math, outline, search, live reload, document doctor and optional AI.

## Category
Chrome Web Store: **Developer Tools**. Edge: **Developer tools**. Firefox: **Other → Developer tools**.

## Full description

Markscope turns any Markdown file in your browser into a fast, readable, navigable document. It is built for developers who live in READMEs, specs, ADRs and runbooks.

**Opens Markdown automatically**
• .md, .markdown, .mdx and more, over https, http and local files
• GitHub, GitLab and Bitbucket file pages open as raw Markdown in one click
• Drag and drop files, or open them from disk with live reload

**Reads beautifully**
• GitHub-flavored Markdown: tables, task lists, footnotes, emoji, alerts
• Syntax highlighting with one-click copy and optional line numbers
• Mermaid and Graphviz diagrams, KaTeX math
• Light, dark and system themes; choose typeface, size, line height and width

**Navigates like an IDE**
• Outline sidebar that follows your scroll
• Command palette (Ctrl/⌘ K) and keyboard shortcuts for everything
• Find in document, jump between headings, relative links that stay in the viewer
• Edit view with live preview, plus source view with line numbers

**Keeps docs healthy**
• Document Doctor finds broken anchors, missing images, heading-level jumps, missing alt text and TODOs
• Word count, reading time and document statistics
• Export to HTML or Markdown, or print to PDF

**Optional AI (off by default, bring your own key)**
Summarize, outline, review, explain code or a selection, ask questions, or generate a diagram. Use Anthropic Claude, OpenAI, a local model (Ollama, LM Studio) or any OpenAI-compatible endpoint. Requests go directly to your provider; Markscope has no servers.

**Private and secure by design**
• No analytics, no tracking, no remote code
• Documents render in an isolated extension page with a strict security policy, so scripts in Markdown never run
• Minimal permissions; extra site access is requested only when you need it

## Single-purpose statement (Chrome)
Markscope displays Markdown documents as formatted, navigable pages in the browser.

## Permission justifications

| Permission | Justification |
| --- | --- |
| Content scripts on Markdown URLs | Detects Markdown documents (by URL extension and plain-text content type) to read their text and display them formatted. |
| storage | Saves user settings, recent and favorite documents, and briefly passes a document's text from the page to the viewer. |
| activeTab | Lets the user render the current tab as Markdown from the popup when it was not detected automatically. Access is granted only on click. |
| scripting | Used with activeTab to read the text of the tab the user chose to render, and to register content scripts for URL patterns the user adds. |
| contextMenus | Adds "Open link in Markscope" for Markdown links and repository file pages. |
| Optional host permissions | Requested per site when the user has restricted Markscope's site access, adds a custom URL pattern, or configures an AI provider endpoint. |
| Note on host access | Content scripts must match `*.md`-style URLs on any website to detect Markdown; Chrome treats this as access to all sites. The script only reads the text of plain-text Markdown pages and never modifies other pages. |

## Data usage disclosure (Chrome "Privacy practices")
- Does not collect or use: personally identifiable info, health, financial, authentication, personal communications, location, web history, user activity or website content.
- Website content: processed locally only; optionally sent to the user's own configured AI provider at the user's explicit request.
- Not sold, not used for unrelated purposes, not used for creditworthiness.
- Privacy policy URL: host `docs/PRIVACY.md` (e.g. GitHub Pages) and link it.
