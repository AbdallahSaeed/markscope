Markdown, read like code deserves.

Markscope turns any .md file — on GitHub, a docs server or your own disk — into a fast, safe, navigable document with an outline, search, diagrams, math, live reload and a documentation doctor.

Everything a developer reads in Markdown.

READMEs, ADRs, runbooks, specs and changelogs — rendered properly, navigable instantly.

Diagrams and math that just render

Mermaid and Graphviz diagrams, KaTeX formulas, GitHub alerts, task lists, footnotes and tables. Heavy renderers load only when a document needs them.

Navigate like your editor

An outline that follows you, find-in-document, and a command palette for everything.

⌘ K/JK?

Open a whole folder

Browse a project's docs with a Files tab. Relative images and links just work.

Edit, preview, save

Live-preview editing that saves back to the file — with Discard and Undo.

Document Doctor

Finds broken anchors, missing images, skipped heading levels and TODOs.

Live reload

Watches the file and keeps your place. Pauses in background tabs.

Optional AI — your key, your provider

Summarize, review, explain code or a selection, or draw a diagram with Anthropic Claude, OpenAI, a local model or any compatible endpoint. Off by default; requests go straight from your browser to the provider you choose.

Export & print

Self-contained HTML, the Markdown source, or a clean PDF — even from dark mode.

Private and secure by design.

Markdown files can contain anything. Markscope treats them that way.

Scripts never run

Documents render in an isolated extension page with a strict security policy, after HTML sanitizing. A malicious file can't execute code or overlay the interface.

Nothing leaves your browser

No analytics, no telemetry, no remote code, no Markscope servers. Documents are only sent anywhere if you run an AI action — to the provider you configured.

Open source

Every line is on GitHub, with hundreds of tests including a malicious-document suite. Read the privacy policy.
